# Quiz Application (Java Swing)

A desktop-based quiz application built using Java Swing.

## Features
- Multiple-choice questions
- Timer-based automatic navigation
- Score calculation
- Previous / Next navigation
- Final score screen

## Tech Stack
- Java
- Java Swing (GUI)

## How to Run
1. Clone the repository
2. Compile the Java files
3. Run `Quiz.java`
